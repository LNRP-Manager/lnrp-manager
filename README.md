## 🤖 Über den Bot

Der Landkreis Neustedt Discord Bot stellt verschiedene Funktionen für Discord-Server bereit.

Je nach Konfiguration können unter anderem folgende Funktionen bereitgestellt werden:

- Moderation
- Serververwaltung
- Rollenverwaltung
- Ticketsystem
- Protokollierung
- Informationssysteme
- Verwaltungsfunktionen
- Interaktionen und Befehle
- Weitere serverbezogene Funktionen

Der genaue Funktionsumfang kann je nach Discord-Server unterschiedlich sein.
